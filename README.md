# WEBSTUDIO

Навчальний проєкт, створений у межах курсу **HTML** в
[Neoversity](https://neoversity.com.ua/).

## Про проєкт

WEBSTUDIO — це навчальний проєкт зі створення HTML-розмітки вебсайту студії
веброзробки відповідно до наданого макета у Figma.

Мета роботи — закріпити базові знання HTML, навчитися використовувати семантичні
елементи та створювати структуровану й валідну розмітку вебсторінок.

## Технології

- **HTML5** — структура та семантична розмітка сторінки.
- **Prettier** — форматування вихідного коду.
- **Git** — контроль версій.
- **GitHub Pages** — публікація проєкту.

## Структура проєкту

```text
goit-nw-markup-hw-01/
├── images/
│   ├── ...
├── index.html
├── .gitignore
├── .prettierrc
└── README.md
```

## Реалізовано

- HTML-розмітку всіх основних секцій сторінки.
- Семантичну структуру документа: `header`, `main`, `footer`.
- Навігацію з якірними посиланнями.
- Секції Hero, Features та Team.
- Функціональні посилання для електронної пошти та телефону.
- Оптимізовану структуру HTML відповідно до рекомендацій Code Guide.
